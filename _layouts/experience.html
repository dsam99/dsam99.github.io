Projects

CensusUsage | MIT Program of Information Science

CensusUsage is an open-source research project that I worked at the MIT Program of Information Science. The project incorporates three different sources of data regarding the ACS survey: online news articles, tweets through the Twitter API, and articles from the JSTOR academic journal database.
After cleaning and processing the corpuses, the project applies NLP techniques to better understand the different use cases of the ACS data. Topic modelling is performed on the different corpuses using both the NMF and LDA algorithms. Probability distributions are calculated for bigrams and trigrams. Finally there are various visualizations to show the different topics and word frequencies of the corpus. You can find the github repository here.

GeoCash | HackMIT 2018 : Plaid API 1st Place Winner

Our project GeoCash won first place at HackMIT 2018 for the best usage of Plaid's API. GeoCash is a Meteor.js based webapp to help people to easily view where they are spending their money, through a location-based visualization. We were inspired by Plaid's challenge at HackMIT to "help people make more sense of their financial lives."
We integrated Plaid's API to access users' financial transactions, and Google Maps API as a medium to display a users flow of money. I worked on the backend of the webapp. I programmed in Node.js, using the Express framework. I also worked on integrating the Plaid API to access the transactions information and sending the results to the frontend. The project is located here and the github repo is here.

Timewalk | HackHarvard 2019

TimeWalk is a mobile app that utilizes the HERE API to help keep track of where a user has traveled during a day. The mobile app creates a history of locations that the user has visited, including pictures, times, and place names. TimeWalk was created fully in Javascript. I worked in Node.js to create the backend for our app, which integrated HERE API. I made requests to the API and passed the information to the front-end. The project is located here and a demo is located here.
