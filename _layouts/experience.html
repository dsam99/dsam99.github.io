Nasa Jet Propulsion Laboratory | Deep Learning Research Intern (393K)
June 2019 - August 2019

I was a deep learning research intern for the Mission Control Systems Deep Learning Group (393K). My project aimed to better understand and automate Mars Rover Data transmission.
I queried 3 APIs from the data transmission pipeline to the Ground Data System on Earth to construct a dataset of historical data transmission. I implemented signal processing to compute relevant features and computed feature extraction to evaluate the importance of these features. The data collection software that I engineered is currently in use by GDSA team for data visualization tools.
I implemented a deep neural network to identify anomalous data transmission with 95% accuracy, which is a 4% increase from the existing GDS software. I implemented an Adversarial Autoencoder and a One-Class SVM for anomaly detection in data transmission. My trained models will be deployed in new GDS software and possibly the Mars 2020 mission.
Our abstract was accepted into the SciTech 2020 Conference, and our paper will published in January 2020.

I was a data science research intern for the MIT Program of Information Science under Dr. Micah Altman. I worked on the CensusUsage project, which looked to categorize different use cases of the American Community Survey (ACS) data.
